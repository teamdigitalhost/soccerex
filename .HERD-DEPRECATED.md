# Laravel Herd is DEPRECATED for Soccerex

Date: 2026-05-15

Soccerex local dev does **NOT** use Laravel Herd. Herd's `soccerex.test`
nginx config was removed on this date (backed up at
`~/Library/Application Support/Herd/_deprecated-soccerex-backup/soccerex.test.bak`).

## Canonical local setup

The source of truth for local environment configuration is:

    ~/iCloud/Sites/README.md
    (= /Users/maven/Library/Mobile Documents/com~apple~CloudDocs/Sites/README.md)

Summary of the intended setup (see that README for the authoritative steps):

- **Homebrew nginx** (NOT Herd) listens on ports 80/443
- Config: `/opt/homebrew/etc/nginx/servers/soccerex-local.conf`
- Reverse-proxies `https://soccerex.front` -> Vite dev server on `127.0.0.1:5173`
- Reverse-proxies `https://soccerex.back`  -> Laravel on `127.0.0.1:8000`
- Local CA + cert at `~/.config/teamdigitalhost/certs/`
- `/etc/hosts` maps `soccerex.front` / `soccerex.back` -> 127.0.0.1

## If soccerex.front shows a cert error

That means Herd's nginx is still squatting on ports 80/443 instead of
Homebrew nginx. Do not "fix" it inside Herd. Either:

1. Use the Vite server directly: `http://localhost:5173/`, or
2. Follow the Reverse Proxy / Local HTTPS sections in `~/iCloud/Sites/README.md`
   to hand ports 80/443 back to Homebrew nginx.

Do not re-add Soccerex to Herd.
